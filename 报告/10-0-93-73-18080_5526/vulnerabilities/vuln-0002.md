# 生产环境凭据备份 /.env.bak 未授权可下载（数据库/AWS/JWT/K8s）

**ID:** vuln-0002
**Severity:** HIGH
**Found:** 2026-10-31 04:11:35 UTC
**Target:** http://10.0.93.73:18080
**Endpoint:** /.env.bak
**CWE:** CWE-552
**CVSS:** 7.5
**Confidence:** High
**Fix Effort:** Low

## Description

目标 Web 根目录下遗留了生产环境变量备份文件 `/.env.bak`，未认证即可完整下载。文件包含 PostgreSQL 与 Redis 连接串及密码、AWS Access Key/Secret、JWT 签名密钥、Kubernetes API 地址与 ServiceAccount 令牌、内部网关地址等敏感凭据。同一 `.env` 文件本体返回 403，说明存在敏感文件过滤，但 `.bak` 备份后缀未被覆盖。

## Evidence

`GET /.env.bak` 返回 200 与完整文件（13641 字节）：

```http

Content-Type: text/plain
Content-Length: 13641
Server: nexus-gateway/2.4.1
```

```env

REDIS_CLUSTER=redis://:m3BCkTYZ7Z6GGEzmwqZg@10.99.48.62:6379,10.99.48.62:6380/0
AWS_ACCESS_KEY_ID=AKIA-RRRRRRRRRRRRRRR

JWT_SECRET=GdVzs21MjXBk7ZFm4H98WVb8d6EDmZU-fnVCLhTt_ec

```

对照请求 `GET /.env` 返回 `403 Access denied`（348 字节），证明过滤存在但被 `.bak` 变体绕过。另 `GET /static/../.env.bak` 返回 200 与同类凭据内容。

## Impact

未认证攻击者可直接获取数据库与缓存口令、云访问密钥、JWT 签名密钥、Kubernetes ServiceAccount 令牌与内部服务地址。这些材料可用于伪造会话令牌、访问数据库/Redis、调用云 API 及尝试访问集群，构成从外部直达内部基础设施的严重凭据泄露。

## Counterevidence

存在基于文件名的过滤：`/.env` 返回 403，说明有敏感文件黑名单；但 `.bak` 后缀绕过该过滤，证明控制不完整且为黑名单式而非默认拒绝。观测到同一文件在不同请求间凭据值会变化，且 `10.99.*`、`git.nexus.internal` 等地址在测试位置不可达，因此无法验证这些凭据在生产系统的真实可用性；报告因此将影响限定为"敏感凭据文件的未授权披露"。另外 `/static/../.env.bak` 也可读到该文件，说明同一数据还可经静态处理器穿越获取。

## Confidence Rationale

直接请求稳定返回 200 与完整凭据文件内容，属动态验证；凭据对下游系统的可用性未验证。

## What Would Change This Severity

若验证泄露的 AWS/K8s/数据库凭据在生产系统仍有效，应上调为严重；若确认该目标为非生产演示环境且凭据均为合成数据，应下调至中危。

## Technical Analysis

静态资源处理器以文档根目录为基准提供文件服务，但未对点文件/备份扩展名实施统一拒绝。`/.env` 被 403 拦截而 `/.env.bak` 返回 200，说明过滤规则是精确文件名黑名单；结合 `/static/../etc/passwd` 的穿越结果，说明路径规范化与过滤均在字符串层面完成，可被后缀变体与 `..` 绕过。

文件内容以 `# Nexus DevOps Platform — Production Environment` 开头，包含完整的连接串与密钥，符合生产环境变量文件的特征。

## Proof of Concept

1. 直接请求 `GET /.env.bak`，响应 200，返回包含数据库、Redis、AWS、JWT、K8s 凭据的完整文件。
2. 对照请求 `GET /.env`，响应 403，说明仅 `.env` 被拦截。
3. 请求 `GET /static/../.env.bak`，同样返回 200 与凭据内容，说明该文件还可经静态路由穿越读取。

```python
curl -i "http://10.0.93.73:18080/.env.bak"
curl -i "http://10.0.93.73:18080/.env"            # 403 对照
curl -i "http://10.0.93.73:18080/static/../.env.bak"
```

## Remediation

1. 立即从 Web 根目录删除 `/.env.bak` 及任何备份/临时文件，并将密钥移出代码目录。
2. 轮换已泄露的数据库、Redis、AWS、JWT 与 Kubernetes 凭据，并审计其近期使用记录。
3. 以默认拒绝策略阻止点文件与备份扩展名（`.env*`、`.bak`、`.old`、`.swp`、`.git*`）被静态服务返回，而非仅拦截精确文件名。
4. 静态资源目录与运行时配置目录物理分离，网关进程仅挂载必要的静态目录。
5. 在 CI 中加入密钥扫描，防止环境变量文件进入部署包。

## Assumptions

攻击者无需凭据，直接匿名访问即可。所泄露凭据在目标描述中标注为生产环境；其是否对外部系统真实有效未在本次测试中验证。
